# RESTful API для управління завданнями (Go + SQLite)

## Опис 
Цей проєкт є розрахунковою роботою з дисципліни  
**«Інструментальні засоби розробки програмного забезпечення»**.

Реалізовано RESTful API для управління завданнями (ToDo-система) з використанням мови програмування Go та бази даних SQLite.

---


##  Технології
- Go (Golang)
- SQLite
- net/http
- JSON API

## Запустити проєкт
go run main.go
